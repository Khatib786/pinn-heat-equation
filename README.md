# Physics-Informed Neural Network for the 2D Transient Heat Equation

This project implements a Physics-Informed Neural Network (PINN) for solving the 2D transient heat equation:

$$
u_t = \alpha(u_{xx} + u_{yy})
$$

The model is trained using a Gaussian hot-spot as the initial condition. Its results are compared with an independently implemented and verified finite-difference (FD) solver. The project also studies the computational cost of the PINN and examines how network depth and collocation point density affect its performance.

## Headline Results

| Measure                                                       | Result                 |
| ------------------------------------------------------------- | ---------------------- |
| PINN vs. FD accuracy (relative L2, across 5 evaluation times) | **0.39% – 0.67%**      |
| FD solver validation against analytical solution              | **O(Δx²) convergence** |
| PINN training time (20,000 epochs, CPU)                       | **28.0 min**           |
| FD single-solve time (64×64 grid)                             | **4.09 ms**            |
| Break-even query count for PINN training cost                 | **≈ 3.36 million**     |

## Main Finding

The PINN provides accurate results, but its training cost is much higher than the cost of running the FD solver for this problem size. The FD solver takes only a few milliseconds for a single 64×64 solve, so the PINN training cost would require approximately 3.36 million repeated queries to be amortized.

The sensitivity study also shows that network depth had a much stronger effect on accuracy than increasing the number of collocation points. Under the reduced training budget, increasing the network from 3 to 5 hidden layers reduced the error substantially, while increasing collocation points from 2,500 to 10,000 produced no measurable improvement.

The full analysis, including the problem setup, numerical methods, autograd issue and its fix, results, and discussion of the amortized cost, is available in [PAPER.md](PAPER.md).

## Reproduce the Results

Install the required packages first:

```bash
pip install -r requirements.txt
```

### 1. Check the Autograd Implementation

Run the autograd checks before running the main experiment:

```bash
python experiments/phase0_autodiff_check.py
```

### 2. Run the Main Experiment

This validates the FD solver, trains the PINN for 20,000 epochs, compares the PINN with the FD reference, and generates the figures.

```bash
python experiments/baseline.py
```

The full training run takes approximately 28 minutes on CPU.

### 3. Run the Amortized-Cost Analysis

This uses the checkpoint generated by the main experiment:

```bash
python experiments/benchmarking.py
```

### 4. Run the Sensitivity Study

The sensitivity experiment tests different collocation counts and network depths. A reduced training budget is used by default to keep the runtime practical.

```bash
python experiments/sensitivity.py --epochs 3000
```

To use the same 20,000-epoch budget as the main experiment:

```bash
python experiments/sensitivity.py --epochs 20000
```

All experiments use a fixed random seed:

```text
RANDOM_SEED = 42
```

This is defined in `src/config.py` and helps make the experiments reproducible.
